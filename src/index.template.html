使い方と注意事項

基本操作

  1. 「ファイルを選択」またはドラッグ＆ドロップで音声ファイルを追加します。複数のファイルをまとめて追加できます。
  2. 追加されたキューボタンを押すと再生します。別のキューを押すと、前の曲を止めてその曲へ切り替わります。
  3. 画面下部のプレイヤーから一時停止・再開・停止できます。
  4. 各再生ボタンの編集から、表示名・開始位置・終了位置・音量・フェード・ループ・キーボードショートカットを設定できます。並べ替えはカード下部のグリップをドラッグするか、Tabでグリップを選択して↑ / ↓キーを押します。Escでドラッグを取り消せます。選択中のキューがあれば即時停止も行います。
  5. 「再生専用表示」にすると編集操作を隠し、曲を鳴らす操作だけに集中できます。編集へ戻るには解除ボタンを長押しします。

再生専用表示

再生専用表示では、必要に応じて全画面表示と画面の点灯維持を有効にできます。どちらもブラウザが対応している場合だけ利用できます。

キーボード操作

入力欄やダイアログを操作していないときは、Spaceで再生/一時停止、Rで最初から再生、Fでフェード停止、Escで即時停止できます。キューごとに0–9 / A–Zの1キーも割り当てられます。

プライバシー

追加した音声はこのブラウザ内だけで読み込まれ、このアプリから外部サーバーへ送信されません。実行時の外部通信も行いません。

v1.0.0 の注意事項

  • 音源とキュー設定はこのブラウザへ自動保存され、次回の起動時に復元されます。ブラウザのサイトデータを削除すると保存内容も削除されます。
  • 「保存を保護する」は保存を保証するものではありません。重要なボードは .bkcue バックアップも保存してください。バックアップは音源を含みます。
  • 再生できる形式はブラウザによって異なります。MP3 / WAV / M4A / OGG / WebM / FLAC など、ブラウザが対応する音声を利用できます。
  • 1ファイル2 GiBを上限としています。大きな音声は端末やブラウザの性能によって読み込みに時間がかかる場合があります。

再生専用表示・バックアップ・単一HTML Player Export を利用できます。
